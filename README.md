# UTOPIA SYNDROME Pixel Alpha 0.1

SCP 모티브 세계관 `UTOPIA SYNDROME`을 기반으로 한 2D 픽셀 싱글 서바이벌 웹게임 알파 버전입니다.

## 실행 방법

1. ZIP 압축을 풉니다.
2. `index.html`을 브라우저로 엽니다.
3. 특성 4종 중 하나를 선택하고 게임을 시작합니다.

## 조작법

- WASD / 방향키: 이동
- E: 상호작용
- Shift: 달리기
- N: 다음 날

## 포함된 기능

- 2D Canvas 픽셀 맵
- 플레이어 이동
- 벽 충돌
- 특성 선택: 격리 / 연구 / 전투 / 피실험
- 생존 상태: HP / 정신 / 오염 / 기지 안정도
- 힘 수치: 근력 / 체력 / 각성
- 지능 스탯
- 운동 시설
- 연구 시설 / 책 읽기
- DNA 보관실 / DNA 상점
- 저위험 격리실 점검
- 고위험 격리문 점검
- 교회 통신 단말
- 랜덤 격리 실패 이벤트
- Day 진행
- localStorage 저장 / 초기화
