# UTOPIA SYNDROME Pixel Alpha 0.2 - Story Mode

SCP풍 변칙개체 격리 세계관 `UTOPIA SYNDROME`을 기반으로 한 2D 픽셀 싱글 서바이벌 웹게임 알파 버전입니다.

이번 버전에서는 기존 Survival Mode에 더해 `Story Mode`가 추가되었습니다.

## 실행 방법

1. ZIP 압축을 풉니다.
2. `index.html`을 브라우저로 엽니다.
3. 타이틀 화면에서 `Survival Mode` 또는 `Story Mode`를 선택합니다.

## 조작법

- WASD / 방향키: 이동
- E: 상호작용
- Shift: 달리기
- N: 다음 날
- Enter: 대사 넘기기

## Story Mode 진행 범위

### Prologue

USI 신입 인원으로 배정됩니다.

### Chapter 0. 신입 배정

목표:

1. 관리실의 SITE 단말기 확인
2. 훈련실 이동
3. 연구 시설에서 연구원 하엘과 대화
4. 저위험 격리실 점검
5. 관리실에서 첫 보고서 작성

마지막 이벤트:

- AH-1 / 52Hz 웨일 신호 이상 증폭
- Chapter 1 진입

### Chapter 1. 52Hz Signal 도입부

목표:

1. 교회 통신 단말 확인
2. 저위험 격리실에서 AH-1 신호 기록 수집
3. 관리실에서 주파수 차단 시도

결과:

- 지능 + 각성 판정에 따라 차단 성공/실패
- 성공 시 쿼츠 보상
- 실패 시 정신/기지 안정도 감소
